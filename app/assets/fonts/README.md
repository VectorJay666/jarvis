# Greeting font

The greeting and philosophical lines use glyphs from LXGW WenKai Regular, downloaded from the official lxgw/LxgwWenKai repository on October 12, 2026.

Upstream source: https://github.com/lxgw/LxgwWenKai
Font source: https://raw.githubusercontent.com/lxgw/LxgwWenKai/main/fonts/TTF/LXGWWenKai-Regular.ttf

JarvisGreeting-Regular.ttf is a mobile subset containing the four time-of-day greetings and the current quote collection. Glyph outlines are unchanged; the font family is renamed to Jarvis Greeting to honor the upstream reserved font names. Original copyright and license metadata are retained. See OFL.txt for the complete license.

When adding greeting or quote text, regenerate this subset with the new characters before using this font for it.

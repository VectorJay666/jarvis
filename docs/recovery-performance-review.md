# 对话速度、首页分流与动效验证（2026-10-12）

首页改为单次模型调用理解意图并回答。普通问题、预算、运动、饮食保留在首页，只有明确 sleep 且置信度不低于 0.85 时进入睡眠模式，传递完整会话和已有回复，不重复调用。睡眠对话是模块里的“陪我调整”模式，“体验示例”明确使用模拟记录。

模型配置保留实际可用的 `gpt-6-sol`，设置 `reasoning_effort=low` 并缩短结构化输出。相同任务两次测试首段回复分别约 3.6 / 9.5 秒、完成约 6.1 / 11.3 秒；对照 `gpt-6.1-sol` 两次首段约 6.9 / 8.8 秒、完成约 13.3 / 12.6 秒。样本很小，不代表固定延迟。一些列在模型清单里的候选模型实际返回账号不可用或超时，因此没有仅凭名字切换。

流式接口逐段提取 JSON 顶层 reply，过滤推理字段；完整结构通过校验才显示卡片。取消、关闭、超时和失败均保留用户消息，支持重试。客户端先展示有呼吸反馈的球，再平滑展示实际收到的文字，消息和卡片使用连续布局动效，输入栏为毛玻璃，用户向上查看历史时不会强行拉到底。减少动态效果时关闭装饰动画。

## 验证结果

- TypeScript 通过，lint 0 错误、14 个既有警告。
- 20 项 Node 测试通过，包括中文逐字节 SSE、转义、推理隔离、截断失败、客户端协议、否定语境、置信度、关闭连接取消生成。
- Web 导出和 iOS JS/Hermes bundle 导出通过。
- 浏览器首页 10 组检查通过：问候区域约40%、横排小点、哲理句、手指跟随、吸附、毛玻璃、导航、输入球反馈、360×640布局、减少动态效果。
- 浏览器流式交互 10 组检查通过：等待、逐段正文、完成卡片、预算留首页、明确睡眠交接、单次调用、错误重试、停止/返回取消、示例证据、360px布局、历史滚动与减少动效。均无页面运行异常。
- 5 项真实首页接口测试通过：代码 general、否定睡眠后的预算 budget、模糊疲惫 general、明确失眠 sleep、多主题 general。首段约 3.6–9.5 秒，完成约 4.2–13.8 秒；这是本次实测范围，非保证。
- 发布配置检查通过：未配置、HTTP、本地/私有地址、带账号密码的地址拒绝；公开 HTTPS 地址格式通过，移除局域网权限和 HTTP 例外，不影响本地测试配置。

本轮没有 Xcode 原生编译、iPhone 真机测试或 TestFlight 上传。iOS bundle 导出只验证代码打包，原生玻璃、通知、签名和真实帧率需设备实测。其他主题目前在首页按对应内容回答，尚无独立完整的饮食/运动业务模块。
